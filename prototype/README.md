# Prototype Liste de Prénoms - Compose

## Description
Ce projet est un **prototype Android en Jetpack Compose** permettant :
- D’ajouter des prénoms dans une liste.
- D’afficher les prénoms avec un emoji 👤.
- L’interface est réactive grâce à `mutableStateListOf`.

## Fonctionnalités
1. Champ de saisie pour entrer un prénom.
2. Bouton pour ajouter le prénom à la liste.
3. Liste dynamique affichée avec `LazyColumn`.
4. Style du texte avec `MaterialTheme.typography.bodyLarge`.
